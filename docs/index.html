X 媒体下载器
开源浏览器扩展

给 X 加一个下载按钮

视频右上角多出一个小角标，点开能选 X 服务器上的全部清晰度； 图片直接存原图。全程不经过编码器，下载到的就是服务器上那份文件。

720p列出全部档位与码率，任选一档
原图缩略图地址改写为 name=orig
0 延迟角标随页面原生滚动，不卡顿
下载安装包 查看源码
安装只需四步：
  1. 下载 zip 并解压，进到能看到 manifest.json 的那一层
  2. 浏览器打开 edge://extensions/，开启「开发人员模式」
  3. 点「加载解压缩的扩展」，选择该文件夹
  4. 刷新 x.com，角标就会出现
